Pixelsynth Paint

This project is a faithful and creative adaptation of the original Max for Live idea, with the benefit of being fully accessible from any browser.

Project repository: vlasvlasvlas/pixelsynth

Thanks to the original Ableton version: little-scale.breakoutesque.amxd

Draw on the grid, launch balls and create pixel-art bugs to generate music.

Tools: Use pencil, bucket, line or circle.

Bugs:
- Wanderers: Walk randomly.
- Cowards: Flee from balls.
- Chameleon: Changes color every N seconds and paints its trail.
